# 躲避副驾驶（dodge-copilot）

玩单机肉鸽游戏时的走位助手：只看屏幕画面，认出角色和子弹、闪电、激光等危险物，预测它们的轨迹，替你躲闪。

- 按 `F8`：助手接管走位；再按一下交还。
- 接管期间你一按方向键，控制权立刻回到你手里。
- 按 `F12`：急停（松开所有键并退出）。

## 边界（请先读）

- 只用于**单机、离线**游戏，不用于任何联机、对战或排行榜模式。
- 只读屏幕像素、只模拟键盘鼠标或手柄输入；不读写游戏内存，不注入代码，不修改游戏文件，不绕过反作弊。
- 使用前请确认游戏的用户协议允许这类辅助工具。

## 先试试测试游戏

需要 Python 3.11 或更新版本。

```bash
pip install -e ".[dev]"
```

```bash
python -m dodge_copilot sim
```

打开后：

| 按键 | 作用 |
|---|---|
| 方向键 / WASD | 自己走 |
| `F8` | 助手接管 / 交还（右上角会变成橙色"助手接管中"） |
| 接管中按任意方向键 | 立刻交还给你（右上角变回绿色"玩家控制"） |
| `F12` 或关窗口 | 急停，退出 |
| `R` | 被打中后重开 |
| `F3` | 显示 / 隐藏每帧耗时 |

M0 阶段助手还只会"随机乱走"，这是用来和以后的真正助手做对比的基准。

## 存活时间（衡量助手好坏的主要数字）

同一组随机种子（0–19），测试游戏默认难度，每局最多 60 秒：

```bash
python -m dodge_copilot bench --seeds 20 --policies idle,random
```

| 策略 | 局数 | 平均存活（秒） | 中位数 | 最短 | 最长 |
|---|---|---|---|---|---|
| 不操作（idle） | 20 | 3.88 | 3.76 | 2.30 | 5.63 |
| 随机乱走（random） | 20 | 4.65 | 4.28 | 2.20 | 8.75 |
| 助手接管 | — | M1 补上 | | | |

测试游戏越往后子弹越密。开发时用一个"能偷看游戏内部状态"的验证脚本试过，默认难度下是可以一直躲开的，所以这个难度是合理的。

## 给游戏写配置

每个游戏一份 `profiles/<名字>.yaml`。仓库里有两份：

- `profiles/testgame.yaml`：测试游戏用。
- `profiles/example.yaml`：示例，每一项都有注释。只想自己用、不想进 git 的配置，命名为 `profiles/local_<名字>.yaml`。

主要内容：截屏区域、玩家怎么找（固定在画面中心 / 按颜色 / 按截图）、危险物颜色和大小、要忽略的界面区域（血条、分数、小地图）、键位、角色移动速度、热键。

配置写错（字段名拼错、类型不对）时程序会直接告诉你是哪一项，不会悄悄忽略。

`takeover.auto_resume_after_s`：你按方向键抢回控制后，默认**不会**自动恢复接管，要再按 `F8`。如果想"松手 1 秒后自动交回给助手"，把它设成 `1.0`。

## 安全措施

- 交还、急停时，助手先松开它按着的所有键。
- 程序崩溃、被 Ctrl+C、被结束进程、关掉控制台窗口时，也会先松开所有键（`try/finally`、退出钩子、信号处理三道保险）。
- 切换延迟远低于 50 毫秒（只是改一个状态、松几个键）。

## 开发者看这里

```
dodge_copilot/
  config.py        配置文件格式和严格检查
  control.py       接管 / 交还 / 急停状态机（线程安全）
  inputs.py        方向 -> 按键或摇杆；记住按了什么，能全部松开
  safety.py        崩溃、退出时松键
  loop.py          一帧：截屏 -> 识别 -> 决策 -> 输入
  perception/      看懂画面（M0：找玩家）
  policy.py        决策（M0：不操作 / 随机乱走）
  stats.py         每帧耗时统计
  bench.py         存活时间基准
  app.py           测试模式的交互窗口
  io/sim.py        测试模式接口：直接对接测试游戏
testgame/          测试用弹幕小游戏：直线、扇形、追踪弹，追人的敌人，激光，闪电；固定随机种子
tests/             单元测试：python -m pytest
```

- 测试游戏的画面用 OpenCV 画成图片，不开窗口也能跑，所以基准和测试可以在没有显示器的机器上跑。交互窗口才用 pygame。
- 测试游戏支持两种镜头：`fixed`（固定场地，有墙）和 `follow`（镜头跟着玩家，玩家永远在中间），在 `profiles/testgame.yaml` 的 `sim.camera` 里改。
- 测试游戏里的"血条"故意用了和子弹很像的红色，用来检验"忽略区"是否生效。
